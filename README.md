# KidsApps 🎮

Обучающие веб-игры для детей. Чистый HTML/CSS/JS — без сборки и сервера, работает на телефоне и компьютере.

## 🐱 Котоматика — таблица умножения с котиками

Игра для ребёнка ~9 лет: учим таблицу умножения, зарабатываем рыбки 🐟 и наряжаем своего котика.

### Что есть

| Раздел | Что делает |
|---|---|
| **Вход** | Профили игроков. Вместо пароля — секретный код из 3 картинок (🐱🐟🧶…). Игра помнит, кто играл последним. После 2 ошибок показывает подсказку. |
| **🗺️ Приключение** | Карта из 10 миров: ×2 «Котёнкин дворик» → … → ×10 «Облачный замок» → «Радужный микс». Уровень = 10 верных ответов. 3 звезды за прохождение без ошибок. Следующий мир открывается после прохождения предыдущего. |
| **➗ Деление** | Вкладка на карте: 10 «вкусных» миров (Пицца пополам, Конфетная лавка…), делим угощение поровну. Мир деления открывается, когда пройден такой же мир умножения. Разбор ошибки: «проверяем умножением» и картинка из групп. |
| **✏️ Столбик** | Сложение и вычитание в столбик, 6 уровней: без перехода → с переходом → трёхзначные. Ответ вводится по разрядам справа налево, «1 в уме» и точка займа появляются над цифрой. При ошибке котик объясняет именно этот разряд. |
| **🎣 Кото-ферма** | Каждый верный ответ — 1 🦐 корма (пример в столбик — 2). Запускаешь рыбку в пруд, кормишь, она растёт, ловишь — получаешь рыбки 🐟. 6 видов рыб от карасика до китёнка, пруд можно расширять. |
| **🥚 Питомцы** | Яйца как в Adopt Me: обычное и золотое, 11 питомцев трёх редкостей. Питомец ходит рядом с котиком и даёт бонус: щенок — +1 жизнь в битве, сова — +10 секунд в блице, аксолотль — рыбы растут быстрее и т.д. Повторов нет. |
| **🐈 Коллекция** | 12 пород: британец, сиамский, мейн-кун, вислоухий, бенгальский, сфинкс, трёхцветный, персидский, рэгдолл, космокот… Каждая открывается за свой подвиг в разных режимах. |
| **⚡ Блиц** | 60 секунд, ответ вводится с клавиатуры (это тренирует вспоминание, а не угадывание). Можно выбрать таблицы. Рекорд сохраняется. |
| **👑 Битва с боссом** | Крысиный Король, Пёс Барбос, Робо-Мышь и др. Верный ответ — удар, быстрый ответ (< 3,5 с) — критический удар. Если долго думать — босс атакует. С каждой победой босс сильнее. |
| **🛍️ Наряды** | Магазин в стиле Toca Boca, 8 разделов и больше 80 вещей: шёрстка (вплоть до «Галактики»), шапки (от бантика до алмазного шлема из Minecraft и королевской короны), очки, украшения, крылья и плащи, предметы в лапке (алмазный меч, волшебная палочка), анимированные сияния, 16 фонов. Редкость по цене: редкое / эпическое / легендарное, самые дорогие стоят до 2000 🐟. Перед покупкой котик примеряет вещь. Особые вещи — только за подвиги. |
| **📊 Карта знаний** | Таблица 9×9 для умножения и деления: цветом показано, какие примеры уже выучены. Кнопка 📊 на карте миров. |
| **🏆 Награды** | 27 достижений, за каждое +10 рыбок. |
| **🎯 Задание дня** | 20 верных ответов → сундук с рыбками. Серия дней 🔥 увеличивает награду. |

### Как устроено обучение

- **Интервальное повторение** (коробки Лейтнера): каждый пример хранит, насколько хорошо он выучен. Ошибочные примеры попадаются чаще, выученные — реже.
- **Разбор ошибки**: при ошибке котик показывает картинку из точек (по 7 взять 8 раз), запись сложением и хитрость для этой таблицы (на 9: «умножь на 10 и отними число»). Ошибочный пример вернётся через 3 вопроса.
- **Обратные примеры**: когда пример уже знаком, иногда попадается `7 × ? = 56` — подготовка к делению.
- Неверные варианты ответов — «соседи» по таблице (7×7, 7×9, 6×8), чтобы нельзя было угадать.

### Запуск

Просто откройте `kotomatika/index.html` в браузере. Или локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000/kotomatika/
```

**Чтобы играть с телефона**, включите GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / root*. Игра будет по адресу `https://<user>.github.io/KidsApps/kotomatika/`. На телефоне: «Поделиться → На экран „Домой“» — откроется как приложение.

### Где хранится прогресс

В `localStorage` браузера. Значит, прогресс привязан к устройству и браузеру. Очистка данных сайта удалит профили.

### Структура

```
kotomatika/
  index.html            — страница
  css/style.css         — стили (адаптивные, mobile-first)
  js/data.js            — миры, магазин, достижения, подсказки
  js/storage.js         — профили в localStorage
  js/sound.js           — звуки через Web Audio (без файлов)
  js/art.js             — нарисованные вещи и фоны (SVG)
  js/cat.js             — SVG-котик + наряды
  js/game.js            — выбор примеров, варианты ответов, уровни
  js/app.js             — общие функции, меню, приключение, блиц, босс, магазин
  js/column.js          — режим «Столбик»
  js/farm.js            — Кото-ферма
  js/pets.js            — питомцы и коллекция пород
  js/main.js            — обработка нажатий и запуск (подключается последним)
```
