# KidsApps 🎮

Обучающие веб-игры для детей. Чистый HTML/CSS/JS — без сборки и сервера, работает на телефоне и компьютере.

## 🐱 Котоматика — таблица умножения с котиками

Игра для ребёнка ~9 лет: учим таблицу умножения, зарабатываем рыбки 🐟 и наряжаем своего котика.

### Что есть

| Раздел | Что делает |
|---|---|
| **Вход** | Профили игроков. Вместо пароля — секретный код из 3 картинок (🐱🐟🧶…). Игра помнит, кто играл последним. После 2 ошибок показывает подсказку. |
| **🗺️ Приключение** | Карта из 10 миров: ×2 «Котёнкин дворик» → … → ×10 «Облачный замок» → «Радужный микс». Уровень = 10 верных ответов. 3 звезды за прохождение без ошибок. Следующий мир открывается после прохождения предыдущего. |
| **➗ Деление** | Вкладка на карте: 10 «вкусных» миров (Пицца пополам, Конфетная лавка…), делим угощение поровну. Мир деления открывается, когда пройден такой же мир умножения. Разбор ошибки: «проверяем умножением» и картинка из групп. |
| **✏️ Столбик** | Сложение и вычитание в столбик, 6 уровней: без перехода → с переходом → трёхзначные. Ответ вводится по разрядам справа налево, «1 в уме» и точка займа появляются над цифрой. При ошибке котик объясняет именно этот разряд. |
| **🎣 Кото-ферма** | Каждый верный ответ — 1 🦐 корма (пример в столбик — 2). Запускаешь рыбку в пруд, кормишь, она растёт, ловишь — получаешь рыбки 🐟. 6 видов рыб от карасика до китёнка, пруд можно расширять. |
| **🥚 Питомцы** | Яйца как в Adopt Me: обычное и золотое, 11 питомцев трёх редкостей. Питомец ходит рядом с котиком и даёт бонус: щенок — +1 жизнь в битве, сова — +10 секунд в блице, аксолотль — рыбы растут быстрее и т.д. Повторов нет. |
| **🐈 Коллекция** | 12 пород: британец, сиамский, мейн-кун, вислоухий, бенгальский, сфинкс, трёхцветный, персидский, рэгдолл, космокот… Каждая открывается за свой подвиг в разных режимах. |
| **⚡ Блиц** | 60 секунд, ответ вводится с клавиатуры (это тренирует вспоминание, а не угадывание). Можно выбрать таблицы. Рекорд сохраняется. |
| **👑 Битва с боссом** | Крысиный Король, Пёс Барбос, Робо-Мышь и др. Верный ответ — удар, быстрый ответ (< 3,5 с) — критический удар. Если долго думать — босс атакует. С каждой победой босс сильнее. |
| **🛍️ Наряды** | Магазин в стиле Toca Boca, 8 разделов и больше 80 вещей: шёрстка (вплоть до «Галактики»), шапки (от бантика до алмазного шлема из Minecraft и королевской короны), очки, украшения, крылья и плащи, предметы в лапке (алмазный меч, волшебная палочка), анимированные сияния, 16 фонов. Редкость по цене: редкое / эпическое / легендарное, самые дорогие стоят до 2000 🐟. Перед покупкой котик примеряет вещь. Особые вещи — только за подвиги. |
| **📊 Карта знаний** | Таблица 9×9 для умножения и деления: цветом показано, какие примеры уже выучены. Кнопка 📊 на карте миров. |
| **🏆 Награды** | 27 достижений, за каждое +10 рыбок. |
| **🎯 Задание дня** | 20 верных ответов → сундук с рыбками. Серия дней 🔥 увеличивает награду. |
| **🎵 Звук и музыка** | Бесконечная фоновая музыка сочиняется на ходу: спокойная в меню и приключении, бодрая в блице, приключенческая в битве с боссом. Серия верных ответов звучит всё выше, в последние секунды блица тикают часы, на последней жизни слышно сердце. Котик и питомец анимированно реагируют на события. В ⚙️ можно отдельно выключить звуки и музыку и выбрать громкость музыки. |

### Как устроено обучение

- **Интервальное повторение** (коробки Лейтнера): каждый пример хранит, насколько хорошо он выучен. Ошибочные примеры попадаются чаще, выученные — реже.
- **Разбор ошибки**: при ошибке котик показывает картинку из точек (по 7 взять 8 раз), запись сложением и хитрость для этой таблицы (на 9: «умножь на 10 и отними число»). Ошибочный пример вернётся через 3 вопроса.
- **Обратные примеры**: когда пример уже знаком, иногда попадается `7 × ? = 56` — подготовка к делению.
- Неверные варианты ответов — «соседи» по таблице (7×7, 7×9, 6×8), чтобы нельзя было угадать.

### Запуск

Просто откройте `kotomatika/index.html` в браузере. Или локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000/kotomatika/
```

**Чтобы играть с телефона**, включите GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / root*. Игра будет по адресу `https://<user>.github.io/KidsApps/kotomatika/`. На телефоне: «Поделиться → На экран „Домой“» — откроется как приложение.

### Где хранится прогресс

В `localStorage` браузера. Значит, прогресс привязан к устройству и браузеру. Очистка данных сайта удалит профили.

Если родитель вошёл в аккаунт (⚙️ → «Для родителей» или ссылка на экране «Кто играет?»), прогресс дополнительно сохраняется в облаке Firebase и появляется на других устройствах после входа в тот же аккаунт. Там же — резервные копии за 30 дней и сохранение в файл. Без входа и без интернета игра работает как раньше.

Устройство облачного сохранения, статус и тесты: [docs/firebase-plan.md](docs/firebase-plan.md).

```
  js/column.js          — режим «Столбик»
  js/farm.js            — Кото-ферма
  js/pets.js            — питомцы и коллекция пород

```

## 🏃 Word Run — английские слова в 3D-раннере

Игра для 3–5 класса (A0–A1): бежишь по трассе из 3 дорожек и пробегаешь через ворота с правильным английским словом. Управление — свайп влево/вправо, кнопки внизу экрана или стрелки.

| Что есть | Как работает |
|---|---|
| **10 миров** | Цвета, Животные, Еда, Семья, Школа, Тело, Числа, Одежда, Природа, Действия — 8–10 слов в каждом. Следующий мир открывается после прохождения предыдущего. |
| **Режимы подачи** | 1-е прохождение — картинка → слово, 2-е — русское слово → английское, дальше вперемешку: на слух (с 3-го мира) и «слово → найди картинку на воротах». |
| **Страж** | В конце мира — 5 слов подряд на 3 воротах. |
| **Очки и сердца** | +10 × комбо (растёт каждые 3 верных, до ×5), +50 за мир без ошибок. 3 ❤; ошибка — плюх в лужу и повтор того же слова. Закончились сердца — продолжишь с того же слова. |
| **Подстройка** | 2 ошибки подряд — 2 ворот и медленнее; 8 верных подряд — быстрее; 3 ошибки на слове — подсказка и озвучка. Пробежал мимо ворот — без штрафа. |
| **Мои ошибки** | Ошибочные слова повторяются в следующих забегах, пока не будут отвечены верно 3 раза подряд. Повтори 3 карточки — получишь +1 ❤ на забег. |
| **Озвучка** | `speechSynthesis`, британский голос, скорость 0.85. Верный ответ всегда проговаривается. |
| **Монеты и магазин** | 6 блочных скинов и 6 следов, перед покупкой персонаж примеряет вещь. Сундук за 3 дня подряд. |

**📚 Режим «Контрольная»** — подготовка к контрольной по разделу учебника без бега (кнопка в меню). Раздел 1: виды спорта, места, где ими занимаются, месяцы, числа 1–100, времена года.
- **Карточки**: картинка, слово, британская транскрипция, озвучка обычная и медленная 🐢, перевод, пример с переводом, подсказки (play/go/do, предлоги, коварные числа). Режим «проверь себя» прячет английское слово. Отметка «знаю» сохраняется.
- **Правила** по каждой теме — примеры озвучиваются по нажатию.
- **Тренировка**: 10 вопросов разных типов (картинка → слово, на слух, перевод, собрать слово из букв, play/go/do, где занимаются, какой месяц после, время года, число словами с проверкой дефиса и ошибок вроде fourty). После каждого ответа — пояснение и озвучка, ошибки повторяются в конце.
- **Мини-тест** по теме и **пробная контрольная** (20 вопросов по всем темам) — без подсказок, в конце оценка 2–5 и разбор ошибок.
- Слабые слова попадаются чаще, есть «Повторить мои ошибки». Голос выбирается автоматически (британский естественный, если есть) и меняется вручную.
- Словарь — `wordrun/js/study_data.js` (легко подогнать под конкретный учебник), логика — `study_game.js` (тесты: `tests/unit/wordrun-study.test.js`), экраны — `study.js`.

Запуск: `wordrun/index.html` через локальный сервер (см. выше). 3D — Three.js r149 с jsDelivr, поэтому первый запуск требует интернета. Прогресс — в `localStorage` (`wordrun.v1`), облачного сохранения пока нет.

**Картинки.** Пока вместо картинок эмодзи. Список нужных PNG с описаниями для генерации — [wordrun/IMAGES.md](wordrun/IMAGES.md): файл с правильным именем подхватывается автоматически.

```
wordrun/
  index.html          — страница
  css/style.css       — стили (портрет, mobile-first)
  js/data.js          — миры, слова, скины, следы
  js/game.js          — логика забега без DOM (тесты: tests/unit/wordrun-game.test.js)
  js/storage.js       — сохранение в localStorage
  js/sound.js         — озвучка слов и звуки Web Audio
  js/art.js           — PNG-картинки с запасным вариантом-эмодзи
  js/runner3d.js      — 3D-сцена: трасса, бегун, ворота, Страж
  js/app.js           — экраны, HUD, управление
  img/words|worlds|bosses — сюда класть сгенерированные картинки
```
